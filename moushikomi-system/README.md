# 会員入会申込書アプリ（株式会社まごころグループ）

整骨院・鍼灸院・エステサロン向けの「会員入会申込書」デジタル化アプリです。
iPadで申込書を表示 → 患者様が内容確認 → 手書きサイン → サイン付きPDFを印刷、まで完結します。
GitHub Pages + Render（Flask API）で動いていた旧「申込書アプリ」を、勤怠管理システム・週次/月次報告システム・在庫管理システムと**同じ構成**で作り直したものです。

## 技術構成（グループ標準）

- Next.js 15 (App Router) / TypeScript / React 19
- Tailwind CSS / shadcn/ui ベースのUIコンポーネント
- Prisma + PostgreSQL（本番は Supabase。専用スキーマ `moushikomi` を使うので勤怠管理・在庫管理と同じプロジェクトを共有できる）
- Auth.js (NextAuth v5) — ユーザーID / パスワード認証
- Vercel にデプロイ（スリープしないので起動待ちが無い）

## 画面と機能

| 画面 | 使える人 | 内容 |
| --- | --- | --- |
| ホーム | 全員 | 各機能への入口、作成済み件数 |
| 申込書を作成 | 全員 | テンプレート選択 → 入力（申込日・店舗・担当者・患者情報・プラン） → 患者様確認（大きめ文字・全項目チェック必須） → サイン（指・Apple Pencil） → PDFプレビュー / 印刷（A4縦・AirPrint・PDF保存） |
| 申込履歴 | 全員 | 患者名・日付・種類・店舗名で検索、PDF確認、削除 |
| 顧客管理 | 全員 | 店舗別・カルテ番号順の一覧、カルテ番号・氏名で検索、「PDFをまとめてZIP保存」（バックアップ） |
| テンプレート管理 | 本部（＋許可された店舗） | 新規作成・編集・複製・削除、入力項目の追加/削除/並び替え、チェック項目、プラン・料金、規約、対象部門、「からだラボ標準を読み込む」 |
| 店舗管理 | 本部 | 店舗の追加・名称変更・部門・有効/無効 |
| スタッフ管理 | 本部 | ログインアカウントの追加・編集・無効化・削除 |
| 本部設定 | 本部 | 本部ログインのID・パスワード変更、「店舗アカウントにテンプレート編集を許可する」スイッチ |
| アカウント設定 | 全員 | 自分のパスワード変更 |

権限は 2 種類です。

- **本部 (ADMIN)**: 全店舗・全機能。申込書作成時に店舗を選べる
- **店舗担当 (STAFF)**: 所属店舗に固定。自店の申込書だけ閲覧・削除でき、自店の部門（整骨院 / エステ / 鍼灸）向けのテンプレートだけ表示される。テンプレート管理は本部が許可した場合のみ

## 初期アカウント（シードで作成）

旧アプリは「店舗 = 4桁PIN」「本部 = ID + パスワード」でログインしていました。新システムは全員ユーザーID + パスワードです。

| 種類 | ユーザーID | 初期パスワード |
| --- | --- | --- |
| 本部 | `honbu` | `honbu-magokoro2026` |
| 店舗担当（各店舗） | `store` + 旧PIN（例: 狛江院 = `store1007`） | 旧PIN（例: `1007`） |

店舗一覧（旧 config.js の STORES と同じ）: 整骨院 1001〜1013、エステ 2001〜2004、鍼灸 3001〜3004。
**公開後は本部設定・スタッフ管理からパスワードを変更してください。**

## セットアップ（ローカル開発）

```bash
cd moushikomi-system
npm install
cp .env.example .env   # DATABASE_URL / DIRECT_URL / AUTH_SECRET を設定
npm run prisma:push    # moushikomi スキーマとテーブル作成
npm run db:seed        # 店舗マスタ・アカウント・初期テンプレートを投入
npm run dev            # http://localhost:3003
```
