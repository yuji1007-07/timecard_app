# 株式会社まごころグループ 勤怠アプリ MVP v2

Flask + SQLite で動く自社用のタイムカードWebアプリです。

## 主な機能
- 出勤 / 退勤 / 休憩開始 / 休憩終了
- 管理者ログイン
- スタッフ追加
- 月次集計
- 月別CSV出力
- 店舗別CSV出力
- 全20店舗の初期登録

## 初期登録ブランド
- からだラボ整骨院
- ラコンシェル
- 鍼灸ラコンシェル

## 初期管理者アカウント
- ID: admin
- PASS: admin1234

## 起動手順
```bash
pip3 install -r requirements.txt
python3 app.py
```

ブラウザで以下を開きます。
```text
http://127.0.0.1:5000
```

## 初期化が必要なとき
データベースを作り直して、最新の店舗一覧を入れ直すときは以下を開いてください。
```text
http://127.0.0.1:5000/init-db
```
