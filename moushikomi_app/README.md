# 会員入会申込書アプリ（プロトタイプ）

整骨院・鍼灸院・エステサロン向けの「会員入会申込書」デジタル化アプリです。
iPadで申込書を表示 → 患者様が内容確認 → 手書きサイン → サイン付きPDFを印刷、まで完結します。

## できること

1. **トップ画面** … 各機能への入口
2. **申込書テンプレート選択** … 整骨院 / 鍼灸 / エステ / 回数券 / 物販 / 同意書 など
3. **申込内容入力** … 申込日・店舗・担当者・患者情報・プラン・料金を入力
4. **患者様確認画面** … 大きめ文字で内容と規約を表示、確認チェック
5. **サイン画面** … 指・Apple Pencilで手書き署名（やり直し可）
6. **PDFプレビュー / 印刷** … A4縦レイアウト。AirPrintで印刷・PDF保存
7. **申込履歴一覧** … 患者名・日付・種類・店舗名で検索、PDF再表示
8. **テンプレート管理** … 新規作成・複製・削除・項目の追加/削除/並び替え

## 起動方法

ESモジュールを使っているため、簡易サーバー経由で開いてください
（ファイルを直接ダブルクリックするとブラウザの仕様で動かない場合があります）。

```bash
cd moushikomi_app
python3 -m http.server 8000
```

ブラウザ（iPadなら Safari）で次を開きます。

```
http://（PCのIPアドレス）:8000/
# 同じPCで確認するだけなら http://127.0.0.1:8000/
```

## データの保存先について

- 現在は **ブラウザ内（localStorage）** に保存しています。試験運用に向いています。
- 同じiPad・同じブラウザでのみデータが見えます（端末間では共有されません）。
- ブラウザのデータを消すと申込履歴も消えるため、本運用前にバックアップ／クラウド化を検討してください。
