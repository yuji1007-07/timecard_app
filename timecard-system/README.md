# 勤怠管理システム（株式会社まごころグループ）

スタッフが出勤・休憩・退勤を打刻し、店舗責任者・全体管理者が勤怠を確認・修正・集計・出力できる Web アプリです。
Render + Flask で動いていた旧「タイムカードアプリ」を、週次/月次報告システム・在庫管理システムと**同じ構成**で作り直したものです。

## 技術構成（グループ標準）

- Next.js 15 (App Router) / TypeScript / React 19
- Tailwind CSS / shadcn/ui ベースのUIコンポーネント
- Prisma + PostgreSQL（本番は Supabase。専用スキーマ `timecard` を使うので在庫管理と同じプロジェクトを共有できる）
- Auth.js (NextAuth v5) — ユーザーID / パスワード認証
- Vercel にデプロイ（スリープしないので起動待ちが無い）

## 画面と機能

| 画面 | 使える人 | 内容 |
| --- | --- | --- |
| 打刻 | 全員 | 出勤 / 休憩開始 / 休憩終了 / 退勤、本日の状況、直近10日の履歴 |
| 勤怠管理 | 店舗責任者・全体管理者 | 月×店舗で絞り込み、店舗別集計、打刻一覧（休憩開始・終了も表示）、CSV / Excel 出力 |
| 打刻一括編集 | 店舗責任者・全体管理者 | 1画面で複数行をまとめて修正。変更した行だけ保存。休憩開始・終了から休憩分を自動計算 |
| 打刻編集 | 店舗責任者・全体管理者 | 1件ずつの修正（全体管理者は削除も可） |
| スタッフ管理 | 全体管理者 | 追加 / 編集 / 無効化 / 削除、担当店舗の設定、CSV形式の一括登録 |
| 店舗管理 | 全体管理者 | 店舗の追加・名称変更・有効/無効。ブランドは店舗名から自動判定 |
| アカウント設定 | 全員 | 自分のパスワード変更 |

権限は 2 種類 + 1 状態です。

- **全体管理者 (ADMIN)**: 全店舗・全機能
- **スタッフ (STAFF)**: 自分の打刻のみ
- スタッフのうち「担当店舗」を 1 つ以上持つ人は **店舗責任者** として、担当店舗の勤怠管理・一括編集・出力ができます（合同店舗は担当店舗を複数チェックすればまとめて見られます）

## セットアップ（ローカル開発）

```bash
cd timecard-system
npm install
cp .env.example .env   # DATABASE_URL / DIRECT_URL / AUTH_SECRET を設定
npm run prisma:push    # テーブル作成
npm run db:seed        # 店舗マスタと admin を投入
npm run dev            # http://localhost:3002
```

初期アカウント: `admin` / `admin1234`（ログイン後すぐアカウント設定で変更してください）
