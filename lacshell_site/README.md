# 女性専用 ラ・コンシェル整骨院 町田院 ｜ 公開サイト

スマホ最適化（縦長・最大幅440px）の公式LP（ランディングページ）です。
Claude Design で作成したデザイン（`ラコンシェル整骨院.dc.html`）を、
依存ライブラリなしの**素のHTML/CSS/JS**で実装し直した、そのまま公開できる静的サイトです。

## 公開URL

GitHub Pages で、既存の社内アプリとは**別フォルダ・別URL**に分離して公開しています。

```
https://yuji1007-07.github.io/timecard_app/lacshell/
```

- 公開は `.github/workflows/deploy-pages.yml`（リポジトリ直下）が自動で行います。
- このサイトは `lacshell_site/` だけで完結し、勤怠アプリ・申込書アプリには干渉しません。

## 画面構成（5ページ・1ファイル内でJS切替）

1. **トップ（HOME）** … ヒーロー／初回キャンペーン／お悩み／コンセプト／選ばれる理由／人気メニュー／院長あいさつ／お客様の声／店舗情報
2. **施術メニュー・料金（MENU）**
3. **施術の考え方（CONCEPT）** … 根本治療／3つの特長／ご来院の流れ
4. **スタッフ紹介（STAFF）**
5. **アクセス・店舗情報（ACCESS）** … 地図／店舗詳細／受付時間表

画面下部の固定バー（電話予約 / WEBネット予約 / LINE相談）と
ハンバーガーメニューは全ページ共通です。`#menu` のようなURLハッシュで各ページに直接アクセスできます。

## ローカルで確認する

```bash
cd lacshell_site
python3 -m http.server 8000
# ブラウザで http://127.0.0.1:8000/ を開く
```

## 写真について

`assets/` には**お店の実写真**が入っています（院内・施術・待合室・院長・ロゴ）。
差し替えたい場合は、**同じファイル名**で `assets/` に上書きするだけで反映されます。
（写真は表示速度のため、軽量なJPEGへ変換・最適化済みです）

### 注意・補足
- **`director.jpg`（院長写真）は元素材が 45×60px と低解像度**のため拡大して使用しています。
  少しぼやけるので、**高解像度の写真が用意でき次第の差し替えを推奨**します。
- いただいた素材には **`treatment-room-a.jpg` / `treatment-room-b.jpg`（施術室の写真）** も
  含まれていました。現デザインでは未使用ですが、「院内ギャラリー」などに追加できます。

| ファイル名 | 使われている場所 |
| --- | --- |
| `logo.png` | ヘッダー・フッターのロゴ（透過PNG） |
| `entrance.jpg` | トップのヒーロー（院内・入口） |
| `lounge-a.jpg` | トップ「コンセプト」待合スペース |
| `lounge-b.jpg` | 施術の考え方「カウンセリング」 |
| `director.jpg` | 院長写真（トップあいさつ・スタッフ紹介） |
| `care-shoulder.jpg` | 人気メニュー：首肩こり |
| `care-back.jpg` | 人気メニュー：腰痛 |
| `care-bmk.jpg` | 人気メニュー／施術の考え方：骨盤矯正 |
| `care-highvolt.jpg` | 人気メニュー：ハイボルテージ |
| `care-lower-back.jpg` | 施術の考え方：施術風景 |

> `tools/gen_placeholders.py` は、写真が無いとき用の仮画像生成スクリプトです
> （現在は実写真に差し替え済み）。このツールフォルダは公開物には含まれません。

## よく編集する箇所

- **アクセントカラー**：`index.html` 冒頭の `:root { --accent / --accent-deep }`（現在はローズ基調）
- **予約リンク**：ホットペッパー予約URL・電話番号 `042-860-7700`・LINE `https://lin.ee/...`
- **店舗情報／料金／文言**：各ページの該当箇所を直接編集

## 公開URLが変わったら（独自ドメイン取得時など）

`index.html` の `<link rel="canonical">` と `og:*`（SNS共有用）のURLを、
新しい公開URLに合わせて更新してください。
