# 研修動画管理システム（training-system）

株式会社まごころグループの研修動画を、全店舗のスタッフ（主にスマホ）が視聴し、本部が進捗を管理するためのアプリです。
構成はリポジトリ直下の `CLAUDE.md`（共通ルール）に従っています（`timecard-system` をコピーして作成）。

## 機能一覧

### スタッフ（STAFF）
- **研修動画の一覧**: 自分のブランド向け＋「全部門共通」のうち、自分の役職が対象の動画だけ表示。期限が過ぎた・近い必修動画が一番上。絞り込みタブ（すべて／必修／未完了／完了）
- **視聴チェック**: YouTube（限定公開）を埋め込み再生。実際に再生した部分が **90%以上** で「視聴完了」。早送りで飛ばした部分は数えない（倍速はOK）。次に開くと続きから再生
- **理解度テスト**: 視聴完了後に解放。4択・**80%以上で合格**。回答後に正解と解説を表示。何回でも受け直せる（最高点と受験回数を記録）。問題と選択肢は毎回シャッフル
- **ふりかえり**: 自己評価（1〜5）と「明日からやること」を1行
- **質問**: 再生位置つきで投稿 → 本部が回答すると動画ページに Q&A として表示（名前を出す／伏せるを選べる）
- **自店舗の進捗**（役職が「店長」の人だけ）: 自分の店舗のスタッフの進捗表・必修の未完了者・CSV

### 本部（ADMIN）
- 進捗表（スタッフ×動画。ブランド／店舗／役職／動画のタブ）
- 必修の未完了者リスト（期限切れは赤）
- テストの問題別正答率（選択肢ごとの回答数つき）
- ふりかえり一覧（自己評価の平均とコメント）
- 質問箱（未回答／回答済み）と回答
- CSV出力（進捗表・テスト結果・ふりかえり。BOM付きUTF-8）
- 動画・テスト問題の登録／編集（コードを触らずに追加できる）
- 動画の個人指定（ブランド・役職の対象とは別に、スタッフを1人ずつ指定して見せる。必修にするか・個人の期限を指定ごとに選べる。対象を「個人指定した人だけ」にすることも可能）
- スタッフ管理と CSV 一括登録（氏名, ユーザーID, 店舗名, 役職, 初期パスワード）

## 権限と閲覧範囲（すべてサーバー側で制限）

| | 見られるもの |
| --- | --- |
| ADMIN（本部） | 全店舗・全スタッフの記録、管理画面すべて |
| STAFF | 対象の動画と、**自分の**視聴・テスト・ふりかえり・質問だけ |
| STAFF のうち役職＝店長 | 上に加えて、**自分の店舗**のスタッフの進捗（閲覧のみ） |

- 「役職」（店長／副店長／リーダー／スタッフ）は権限ではなく、責任者向け動画の対象判定と、店長への自店舗進捗の表示だけに使います
- 判定ロジックは `src/lib/videos.ts`（`isVideoVisibleTo` / `isRequiredFor`）に集約

## 視聴チェックの仕組み

- プレーヤー（`src/app/(app)/videos/[id]/player.tsx`）が 0.5秒ごとに再生位置を見て「再生した区間」を作り、5秒ごと・一時停止時・画面を閉じるときに `POST /api/progress` へ保存
- 保存は API ルート（画面の再描画なし）。90%に達した瞬間だけ `router.refresh()` でテストを解放（サーバーアクション内で `revalidatePath` は使っていません）
- サーバー側でも「前回保存からの経過時間 × 約2倍速」を超える再生量は記録しません（不正対策）
- 基準値は `src/lib/constants.ts` の `WATCH_COMPLETE_RATIO`（0.9）と `QUIZ_PASS_RATIO`（0.8）

## ローカル起動

```bash
cd training-system
cp .env.example .env      # DATABASE_URL / DIRECT_URL / AUTH_SECRET を設定
npm install
npx prisma db push        # テーブル作成（training スキーマ）
npm run db:seed           # 店舗マスタ・admin・初期動画4本とテスト問題（既存データは消さない）
npm run dev               # http://localhost:3004
```

初期アカウント: `admin` / `admin1234`（ログイン後すぐにパスワードを変更してください）

## 主なフォルダ

- `prisma/schema.prisma` … テーブル定義（スキーマ `training`）
- `src/lib/seed-data.ts` … 初期データ（動画4本・テスト20問）
- `src/lib/progress.ts` … 進捗表の集計（本部・店長・CSV 共用）
- `src/app/(app)/dashboard` … 研修動画一覧
- `src/app/(app)/videos/[id]` … 視聴・テスト・ふりかえり・質問
- `src/app/(app)/admin/*` … 本部の管理画面
- `src/app/(app)/store-progress` … 店長用の自店舗進捗
- `src/app/api/progress` … 視聴記録の自動保存
- `src/app/api/export/*` … CSV 出力
- `src/app/api/setup` … 初期セットアップ（`/api/setup?key=<AUTH_SECRET>`）

テーブル定義を変えたら `src/lib/schema-sql.ts` を再生成してください（ファイル冒頭にコマンドあり）。
公開後にテーブルや列を足すときは、`src/lib/schema-upgrades.ts` に「何度実行しても安全な SQL」を追加します。デプロイ後に `/api/setup?key=<AUTH_SECRET>` を開き直すと本番DBに反映されます（データは消えません）。
